# Assets needed for I Am Rich Expo App

Add the following files to this directory:

1. **diamond.png** - A diamond image (used in App.js)
   - Recommended: 200x200px or larger, transparent background
   - Can download from: https://cdn-icons-png.flaticon.com/512/2942/2942652.png

2. **icon.png** - App icon (1024x1024px)
3. **splash-icon.png** - Splash screen image
4. **adaptive-icon.png** - Android adaptive icon foreground
5. **favicon.png** - Web favicon

Run `npm install` then `npm start` to launch the app.
